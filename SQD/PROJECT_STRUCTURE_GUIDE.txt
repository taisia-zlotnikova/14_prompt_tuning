# ============================================================================
# КЛАСС: PromptTuningLayer
# ============================================================================

ЧТО ДЕЛАЕТ:
  - Создает обучаемые soft prompts (мягкие подсказки)
  - Конкатенирует их с выходом encoder'а
  - Расширяет attention mask соответственно

КОД:
  self.soft_prompt = torch.nn.Parameter(torch.randn(1, prompt_length, hidden_size))

ИСПОЛЬЗОВАНИЕ:
  soft_prompt_layer = PromptTuningLayer(prompt_length=20, hidden_size=768)
  extended_outputs, extended_mask = soft_prompt_layer(encoder_outputs, attention_mask)

# ============================================================================
# КЛАСС: ModelTuningWrapper
# ============================================================================

ЧТО ДЕЛАЕТ:
  - Оборачивает базовую модель
  - Устанавливает все параметры как trainable
  - Не замораживает НИЧЕГО

КОНФИГУРАЦИЯ:
  requires_grad = True для ВСЕх параметров

ИСПОЛЬЗОВАНИЕ:
  model = AutoModelForSeq2SeqLM.from_pretrained("t5-base")
  wrapped = ModelTuningWrapper(model)
  # Теперь все параметры обновляются при backprop

РЕЗУЛЬТАТ:
  ~220M trainable параметров для t5-base
  Высокий риск переобучения на специфичных датасетах

# ============================================================================
# КЛАСС: PromptTuningWrapper
# ============================================================================

ЧТО ДЕЛАЕТ:
  - Оборачивает базовую модель
  - Замораживает ВСЕ параметры LM
  - Добавляет и обучает только soft prompts

КОНФИГУРАЦИЯ:
  requires_grad = False для всех параметров LM
  requires_grad = True только для PromptTuningLayer

ИСПОЛЬЗОВАНИЕ:
  model = AutoModelForSeq2SeqLM.from_pretrained("t5-base")
  wrapped = PromptTuningWrapper(model, prompt_length=20)
  # Теперь обучаются только prompts (~50K параметров)

РЕЗУЛЬТАТ:
  ~50K trainable параметров для t5-base + prompt_length=20
  Меньше риск переобучения, лучше обобщаемость

# ============================================================================
# МЕТРИКИ ПЕРЕОБУЧЕНИЯ
# ============================================================================

1. TRAIN-TEST GAP
   Gap = |Train_Metric - Test_Metric|
   Что означает:
   - Gap = 0.05 -> модель хорошо обобщается
   - Gap = 0.30 -> модель переобучилась
   Интерпретация:
   - Model Tuning обычно имеет большой gap
   - Prompt Tuning обычно имеет малый gap

2. DISTRIBUTION SHIFT IMPACT
   Drop% = (InDist - OOD) / InDist * 100
   Что означает:
   - Drop = 10% -> хороша устойчивость
   - Drop = 50% -> плохо устойчива к shift'у
   Интерпретация:
   - Model Tuning: сильно зависит от исходного датасета
   - Prompt Tuning: более устойчива к новым датасетам

3. SPURIOUS CORRELATION PROXY (CV)
   CV = StdDev(scores) / Mean(scores)
   Что означает:
   - CV = 0.05 -> все датасеты дают похожие scores
   - CV = 0.50 -> результаты сильно варьируются
   Интерпретация:
   - High CV -> модель выучила dataset-specific features
   - Low CV -> модель выучила general features
